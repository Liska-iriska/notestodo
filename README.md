# NOTEStodo — Frontend

Modern web application for managing personal notes.

## 🚀 Live
> ⚠️ **Note:** This application is currently optimized and styled for desktop screens only.
https://notestodo-gold.vercel.app

## 🛠️ Tech Stack

- Next.js 15 (App Router)
- React
- TypeScript
- TanStack Query
- Axios
- Zustand
- CSS Modules

## ✨ Features

- 📝 Create, view, delete notes
- 🔍 Search notes
- 🏷️ Filter by tag (Done / Undone)
- ⭐ Sort by rate (1-10 / 10-1)
- 📄 Pagination
- 🔐 JWT Authentication
- 📱 Desktop design

## 🔧 Getting Started

```bash
npm install
npm run dev
```
